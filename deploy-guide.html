🚀 第四步：构建 & 部署前端

将编译后的前端文件上传到 OSS，让公网可访问
1

在项目根目录创建 📄 .env.production 文件（复制 .env.production.example 后修改）：

# 将 URL 替换为第二步获取的 FC HTTP 触发器地址 VITE_ANALYTICS_API=https://your-account-id.cn-hangzhou.fc.aliyuncs.com/2016-08-15/proxy/sales-lead-analytics/
2

在命令行中执行构建：

# 在项目根目录 sales-lead-agent/ 下执行 npm run build
✅ 构建成功后会生成 dist/ 目录，里面包含所有需要上传的文件。
3

将 📁 dist/ 目录下的 所有文件 上传到 OSS Bucket 根目录

📍 上传方式（二选一）
🖱️ 方式一：控制台上传
1. OSS 控制台 → 进入 Bucket
2. 文件管理 → 上传文件
3. 选择 dist/ 下所有文件和文件夹
4. 确认上传
💡 适合初次操作，直观可见
⌨️ 方式二：命令行上传
ossutil cp -r dist/ oss://sales-lead-app/ --update
需先安装 ossutil 并配置 AccessKey
💡 适合后续频繁更新部署
⚠️ 上传时注意 保持目录结构！assets/ 文件夹要作为子目录上传，不要把里面的文件直接放到根目录。
4
